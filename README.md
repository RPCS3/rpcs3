# RPCS3 Xbox 360 - Experimental

Xbox 360 XDK/Visual Studio 2010 research prototype. Not a functioning PS3 emulator; cannot run PS3 games.

Open `VisualStudio2010/RPCS3Xbox360.sln` using VS2010 and the Xbox 360 XDK. Build and hardware verification pending.

This project originated as a fork of RPCS3 (https://github.com/RPCS3/rpcs3). Original code is preserved on `master`. GPLv2 license retained. Do not redistribute proprietary Xbox SDK files.
